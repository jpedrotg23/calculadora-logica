# Calculadora de Lógica Proposicional

Ferramenta web acadêmica para montar expressões de lógica proposicional, gerar tabelas-verdade e classificar o resultado lógico das fórmulas.

## Funcionalidades

- Montagem de expressões com as variáveis proposicionais A, B e C.
- Operadores de negação (`~`), conjunção (`^`), disjunção (`v`), implicação (`→`) e equivalência (`↔`).
- Geração das combinações de valores lógicos.
- Exibição da tabela-verdade.
- Classificação da expressão como tautologia, contradição ou contingência.
- Ações para apagar o último caractere ou limpar a expressão.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como utilizar

A aplicação é composta por um único arquivo HTML. Abra `index.html` diretamente no navegador ou utilize o Live Server no VS Code.

## Escopo e limitações

Este é um projeto didático. A validação sintática atual é simplificada e verifica principalmente os parênteses; ela não substitui um parser completo de lógica proposicional. A avaliação das expressões também segue a implementação atual do protótipo.

## Objetivo de aprendizado

Aplicar conceitos de lógica proposicional, combinações booleanas, avaliação de expressões e geração de tabelas-verdade por meio de JavaScript.
